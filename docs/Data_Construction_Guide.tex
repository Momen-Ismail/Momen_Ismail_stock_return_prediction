\section{Objective and Final Dataset}

The pipeline constructs a monthly stock-level dataset for predicting next-month excess returns. Each observation is one ticker-month. Predictors are measured using information available by the end of month $t$, and the target is the stock's excess return in month $t+1$:
\[
  y_{i,t+1}=r_{i,t+1}-RF_{t+1}.
\]

The final model-ready file is intended to be
\path{output/data/final/model_dataset_kelly_ranked_full_1990_2025.parquet}.
It contains \code{ticker}, \code{month}, the raw target \target, and rank-normalized predictors. The common data file does not define train, validation, or test samples; chronological splitting is deferred to the model workflow.

The sample starts in January 1990 and ends in December 2025. Daily price data begins in 1987 so that long-window predictors can be formed by 1990. The price window ends in early 2026 because January 2026 returns are needed to realize the December 2025 next-month target.

\section{File 01: Daily Stock Prices and Quality Cleaning}

\textbf{Input:} \code{input/stock\_universe\_locked.csv}. \\
\textbf{Output:} clean daily prices, ticker-quality report, and removed-ticker report. \\
\textbf{Purpose:} create a clean daily OHLCV stock-price panel.

File 01 loads the locked universe, downloads Yahoo data with \code{auto\_adjust=False}, standardizes columns, and computes daily adjusted returns:
\[
  r_{i,d}=\frac{AdjClose_{i,d}}{AdjClose_{i,d-1}}-1.
\]

The daily cleaning rules remove bad rows for:
\begin{itemize}
  \item impossible OHLC relations, such as \code{high < low};
  \item missing core fields: open, high, low, close, adjusted close, or volume;
  \item nonpositive adjusted prices;
  \item duplicate ticker-date rows;
  \item extreme daily returns above 300\% or below $-95\%$.
\end{itemize}

A whole ticker is removed only if its bad-row share exceeds \code{DAILY\_BAD\_ROW\_SHARE\_THRESHOLD}, currently 10\%. This avoids throwing away a complete stock history because of a small number of bad observations.

\section{File 02: Monthly Stock Features and Target}

\textbf{Input:} clean daily stock prices, permanent GSPC/VIX daily files, and permanent Fama--French RF. \\
\textbf{Output:} \code{monthly\_stock\_panel\_with\_targets\_1990\_2025.csv}. \\
\textbf{Purpose:} construct monthly price-based predictors and the next-month excess-return target.

Monthly return is computed from month-end adjusted prices:
\[
  r_{i,t}=\frac{AdjClose_{i,t}}{AdjClose_{i,t-1}}-1.
\]
Momentum variables are compounded from lagged monthly returns, so the current month is excluded:
\[
  mom_{i,t}^{(k)}=\prod_{j=1}^{k}(1+r_{i,t-j})-1.
\]
The retained momentum variables are \code{mom6m}, \code{mom12m}, and \code{long\_term\_return\_36m}. All are based on lagged monthly returns, so the current month is excluded.

Liquidity and trading variables include Amihud illiquidity:
\[
  Amihud_{i,d}=\frac{|r_{i,d}|}{AdjClose_{i,d}\times Volume_{i,d}},
\]
then averaged within month as \code{amihud\_1m}. Other monthly variables include realized return volatility, minimum daily return, average of the five largest daily returns, zero-volume share, dollar-volume growth, price-to-moving-average, distance from the 12-month high, and average intramonth range.

The file removes ticker histories with repeated implausible monthly returns. A ticker is removed if it has at least two monthly returns above 300\% or below $-95\%$.

Market and VIX controls are added directly. VIX is used as an aggregate volatility and risk-aversion state variable following the standard Cboe VIX methodology \cite{cboe2019}. These four variables are direct market-state predictors, not Welch--Goyal variables, and they are not interacted with the macro states:
\[
\code{market\_ret\_1m},\quad \code{market\_vol\_1m},\quad
\code{vix\_avg\_1m},\quad \code{vix\_change\_1m}.
\]
Rolling beta and idiosyncratic volatility are estimated from daily stock and market returns over a 252-trading-day window, with at least 126 observations:
\[
  \beta_{i,t}=\frac{\operatorname{Cov}(r_{i,d},r_{m,d})}{\operatorname{Var}(r_{m,d})},
  \qquad
  \sigma^{idio}_{i,t}=\sqrt{\operatorname{Var}(r_{i,d})-\beta_{i,t}^{2}\operatorname{Var}(r_{m,d})}.
\]
The locked risk block also includes \code{betasq\_12m}, calculated as \code{beta\_12m ** 2}.

The target is created by shifting each stock's monthly return forward one month and subtracting the next-month risk-free rate:
\[
  \target_{i,t}=r_{i,t+1}-RF_{t+1}.
\]

\section{File 03: Compustat Characteristics and Timing}

\textbf{Input:} monthly stock panel and raw annual Compustat file. \\
\textbf{Output:} \code{monthly\_panel\_with\_compustat\_macro\_1990\_2025.csv}. \\
\textbf{Purpose:} add accounting characteristics without look-ahead bias.

Compustat \code{datadate} is the fiscal-year-end date, not the date at which the report is publicly available. The project therefore imposes a conservative six-month availability lag:
\[
  AvailableMonth = MonthEnd(datadate + 6\ months).
\]
For each ticker-month, the merge uses the most recent Compustat report whose available month is not later than the stock month. This is a backward as-of merge and prevents future accounting information from entering predictors.

\section{File 04: Raw Predictor Panel and Interactions}

\textbf{Input:} monthly panel with Compustat variables and cleaned Welch--Goyal macro input. \\
\textbf{Output:} raw Kelly-style model dataset and raw predictor list. \\
\textbf{Purpose:} define the final raw predictor matrix before imputation and normalization.

File 04 keeps 47 locked stock characteristics and 4 direct market/VIX controls. It adds SIC2 industry dummies, including \code{sic2\_missing}, and merges eight locked Welch--Goyal macro states. The interactions are:
\[
  Interaction_{i,t}^{c,m}=Characteristic_{i,t}^{c}\times MacroState_{t}^{m}.
\]
Their purpose is to allow the predictive relevance of firm characteristics to vary with aggregate conditions, consistent with conditional expected returns and state-dependent risk premia. The code does not create market $\times$ macro, VIX $\times$ macro, macro $\times$ macro, SIC2 $\times$ macro, or target interactions.

With the locked design, file 04 creates $47\times8=376$ interaction variables. SIC2 dummy count is data-dependent because it depends on observed industries in the merged panel.

\section{File 05: Imputation and Rank Normalization}

\textbf{Input:} raw Kelly-style predictor panel and raw predictor list. \\
\textbf{Output:} ranked full-sample parquet file, ranked predictor list, and cleaning diagnostics. \\
\textbf{Purpose:} produce the final model-ready full sample.

File 05 drops observations with missing targets because supervised models require observed outcomes. It keeps numeric predictors, drops only predictors that are completely empty, and keeps the raw target rather than winsorizing it. Extreme targets are documented in diagnostic files but not removed from the common dataset.

For each month, missing predictor values are replaced by that month's cross-sectional median. If a predictor is missing for the full month, the fallback value is zero. The predictors are then rank-normalized within month:
\[
  x^{rank}_{i,t}=2\frac{rank(x_{i,t})-1}{N_t-1}-1,
\]
where $N_t$ is the number of firms in month $t$. If a month has only one firm, the transformed value is set to zero. This transformation preserves cross-sectional order, reduces the influence of outliers, and puts predictors on a common scale.

\midrule

Momentum timing & Momentum and long-horizon return use lagged returns and exclude the current month. \\

The main literature motivation is compact: momentum variables follow the return-predictability literature \cite{jegadeesh1993}; price-trend variables follow the 52-week-high logic of George and Hwang \cite{george2004}; valuation and profitability variables follow cross-sectional asset-pricing evidence \cite{fama1992,novymarx2013}; volatility, downside, and maximum-return variables follow risk and lottery-demand evidence \cite{ang2006,bali2011}; illiquidity follows Amihud \cite{amihud2002}; accounting accruals and investment variables follow anomaly evidence from Sloan and Titman, Wei, and Xie \cite{sloan1996,titman2004}; macro states follow Welch and Goyal \cite{welchgoyal2008}; interactions are motivated by modern machine-learning evidence in Gu, Kelly, and Xiu \cite{gkx2020}. Some retained variables reproduce Kelly-style characteristics closely, while others are Yahoo or annual-Compustat proxies. Many Kelly variables remain unavailable because they require CRSP microstructure fields, quarterly Compustat, announcement dates, analyst data, or other external inputs.

\section{Validation Checklist}

After rerunning the pipeline, the following checks should hold before using the file in model estimation:
\begin{itemize}
  \item the final panel has one row per ticker-month and zero duplicate ticker-month rows;
  \item the final target column has no missing values;
  \item all retained predictors are numeric;
  \item no predictor is completely empty after the target drop;
  \item monthly median imputation leaves no missing predictor values;
  \item every rank-normalized predictor lies inside $[-1,1]$;
  \item the ranked predictor list matches the predictor columns in the final parquet file;
  \item the final month is December 2025 and the first model month is January 1990;
  \item the raw target remains unwinsorized in the common data file;
  \item any model-specific winsorization or scaling is fitted only inside the model workflow.
\end{itemize}

These checks are intentionally mechanical. They do not prove that the data is economically perfect, but they verify the central construction contract: correct keys, complete predictors, preserved raw target, chronological timing, and no accidental data leakage in the common panel.

\section{Reproduction Steps}

From the project root, run:
\begin{enumerate}
  \item \code{python src/data/01\_build\_clean\_yahoo\_daily.py}
  \item \code{python src/data/02\_build\_monthly\_stock\_features.py}
  \item \code{python src/data/03\_add\_fundamentals\_and\_macro.py}
  \item \code{python src/data/04\_build\_raw\_kelly\_dataset.py}
  \item \code{python src/data/05\_clean\_and\_rank\_normalize.py}
\end{enumerate}

The normal pipeline should not download Wikipedia, Fama--French, GSPC, VIX, or Welch--Goyal inputs. If those inputs need to be rebuilt, use the one-time scripts in \code{src/acquisition/}.

\section{Limitations}

The project uses a locked S\&P 500-style universe rather than a full CRSP universe. This is practical and transparent but does not fully remove survivorship or selection concerns. Yahoo tickers are also less stable than permanent security identifiers, so the cleaning reports are important. Annual Compustat data is lagged conservatively, but exact filing dates are not used. Finally, the compact predictor set is designed for a clean academic machine-learning project; it is not a full replication of every published anomaly variable.
